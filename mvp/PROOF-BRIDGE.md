# PROOF-BRIDGE — model-side bridge for the MVP lower bound

Owner of this file and of `Civ6Verify/Bounds/MvpOptimality.lean`:
the bridge rescue pass. No model / arithmetic / root / lakefile file was
edited.

Status: **compiles green**, kernel-checked, no `sorry` / `admit` / custom
axiom / `native_decide` / Mathlib. The two headline theorems are real
`OptimalAt` statements on the conditional model `M_MVP(θ*, σ)` — not weakened
by assuming the bridge.

## 1. Headline (what is actually proved)

```lean
theorem optimalAt_baseline : OptimalAt (model baselineParams) goal 20
theorem optimalAt_cost110  : OptimalAt (model cost110Params)  goal 25
```

`OptimalAt M goal N` is `AchievableAt M goal N ∧ NoEarlier M goal N`
(`Civ6Verify/Reachability/Finite.lean`), i.e.

* `baseline_achievable` / `cost110_achievable` (model witnesses, imported), and
* `noEarlier_20` / `noEarlier_25`: no goal state is reachable in fewer ticks,
  where `Reachable` is the exact-step relation generated by the model's own
  `legal` predicate.

Lower-bound chain:

```lean
noEarlier_20   (p) (hcost : p.cost = 8000)  : NoEarlier (model p) goal 20
trained_zero_at_19 (p) (hcost : p.cost = 8000)
                   : ∀ t ≤ 19, ∀ s, Reachable (model p) t s → s.trained = 0
inv_of_reachable (p) (C T) (hcost : p.cost = C) (hT : T ≤ 24) …
                   : ∀ t ≤ T, ∀ s, Reachable (model p) t s → Inv t s
```

`trained = 0` plus `goal s := 1 ≤ s.trained` gives `NoEarlier`; the
`AchievableAt` half is the model's own witness. Nothing here assumes the
intended conclusion as a hypothesis.

## 5. Scope / honest limitations

* Everything is about the **conditional** model `M_MVP(θ*, σ)`
  (`mvp/RULE-CONTRACT.md` v2.1), not about Civilization VI; `[V] = 0`, no build
  is pinned, all constants are the contract's `[C]/[D*]/[A]/[SCENARIO]`
  values.
* The lower bound fixes C2–C7 at baseline; `Params` parameterises only `cost`.
  The `Inv`/`inv_step` development is written against a symbolic `C` with
  `hcost : p.cost = C`, but the θ-uniform statement over the other axes remains
  a contract-family statement until the model parameterises them.
* `prog_le_7560_at_19` is tight and agrees with the model witness
  (`witness_prog_eq_bound`, `prog = 7560` at `t = 19`). It now carries the
  expected `hcost : p.cost = 8000` hypothesis (it previously took an arbitrary
  `p` and passed `rfl` for `p.cost = 8000`, which did not elaborate).
